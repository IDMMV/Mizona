# MiZona Enterprise V8 - Etapa 30.30

Versión preparada con pulido de apariencia móvil, chat estilo WhatsApp claro y mejoras de caja/negocio.

## Cambios principales

- Chat en pantalla completa al abrir conversación.
- Se ocultan barra superior y barra inferior dentro del chat fullscreen.
- Chat claro tipo WhatsApp, con tema/fondo personalizable.
- Lista de chats y conversaciones más compacta en móvil.
- Imágenes visibles dentro del chat.
- Botón Ver chats vuelve a la lista sin salir del módulo.
- Business: al cobrar una venta cambia al flujo de Cocina.
- Business: si el efectivo recibido es menor al total, muestra error.
- Business: se separa Cobrar venta de Imprimir.
- Textos, encabezados y tarjetas más uniformes en celular, tablet y PC.

## Instalación

```bash
npm install
npm run dev
```
