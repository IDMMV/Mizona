# MiZona Enterprise V8 - Etapa 30.46 Mockup móvil fiel

Esta etapa se enfoca en que la app se vea mucho más parecida al mockup aprobado.

## Correcciones principales

### MiZona Chat
- Chat oscuro completo.
- Lista de chats más cercana al modelo tipo app.
- Header de conversación oscuro.
- Botón Salir robusto para volver a Mi Panel.
- Botón Nuevo separado.
- Composer con adjuntar, texto, micrófono y enviar alineados.

### Comités
- Barra principal reducida a 7 pestañas:
  - Inicio
  - Participantes e Integrantes
  - Finanzas
  - Calendario y Agenda
  - Comunicados
  - Reportes
  - Actas y Documentos
- Cuotas, pagos y gastos quedan dentro de Finanzas.
- Actas y documentos quedan juntos.

### Móvil general
- Topbar más limpia.
- Bottom nav tipo app.
- Héroes y cards más similares al mockup.
- Mejoras visuales para Business, Marketplace, Campus, Ride y Beneficios.
