# MiZona Enterprise V8 · Etapa 30.49

Correcciones aplicadas:

- Solicitud de permiso antes de compartir ubicación.
- El bloqueo conserva contacto, conversación e historial en el modo local; muestra estado bloqueado y botón Desbloquear.
- Creación de grupos exige nombre y al menos un contacto, mejora contraste y desplazamiento móvil.
- Encuestas y eventos se publican en el chat, cierran el formulario y muestran confirmación.
- Temas guardados por usuario, color principal aplicado a controles activos y mejor contraste del selector.
- Encabezado del chat permanece compacto y visible cuando aparece el teclado.
- Formularios, textos y controles reducidos para móvil.
- Subtotal, IGV, total y vuelto reorganizados en filas legibles en celular.

## Publicación

Reemplaza el contenido del repositorio por el contenido interior de esta carpeta. En Vercel usa Vite, `npm install`, `npm run build` y salida `dist`.
