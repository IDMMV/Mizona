# MiZona Enterprise V8 · 30.52 — Formato global unificado

Se aplicó un sistema visual común a toda la web: panel, comunidad, comités, chat, beneficios, marketplace, Business, CampusHugo, Ride, finanzas, administración y ventanas modales.

## Cambios principales
- Paleta moderna verde esmeralda con acento violeta.
- Tarjetas, bordes, sombras y radios uniformes.
- Menú lateral y barra superior más compactos.
- Botones, formularios, pestañas y tablas estandarizados.
- Marketplace y ofertas con presentación comercial más limpia.
- Modo claro y oscuro coherentes.
- Mejor adaptación para celular, tablet, escritorio y pantallas grandes.
- Se conservaron las funciones y la organización de la versión 30.51.
