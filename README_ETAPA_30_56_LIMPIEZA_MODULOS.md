# MiZona Enterprise V8 · Versión 30.56

## Limpieza visual real por módulos

Esta versión corrige la mezcla de estilos claros y oscuros y mejora la composición de escritorio.

### Cambios principales

- Pagos MiZona reconstruido visualmente: dos tarjetas coherentes, formularios compactos, controles administrativos legibles y alerta con contraste correcto.
- Campos de formulario reducidos a 44 px y etiquetas uniformes.
- Tarjetas, hero, pestañas, tablas y alertas unificadas.
- Mejor contraste en modo claro y modo oscuro.
- Menos espacios vacíos entre secciones.
- Diseño de escritorio con ancho máximo y columnas equilibradas.
- Mejor adaptación móvil de formularios y controles administrativos.
- Base común aplicada a Finanzas, Pasarela, Centro de Control, IA, Ride, CampusHugo, Business, Marketplace, Comités y Chat.

No requiere SQL nuevo.
