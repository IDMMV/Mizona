# MiZona Enterprise V8 — Etapa 30.89

## MiZona Chat Dark Amber

Esta versión conserva la apariencia clara unificada 30.88 en todos los módulos y aplica únicamente al chat el formato aprobado:

- fondo azul marino profundo;
- paneles carbón azulados;
- mensajes enviados en ámbar;
- mensajes recibidos en gris azulado;
- indicadores de conexión verdes;
- buscador, cabecera, lista de conversaciones y compositor integrados;
- diseño responsive para PC, tablet y celular.

La lógica de chat, Supabase, archivos, encuestas, eventos, ubicación y pedidos no fue alterada.
