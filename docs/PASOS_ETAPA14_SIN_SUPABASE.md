# Publicar la Etapa 14 sin Supabase

1. Descomprime el ZIP.
2. Sube todo el contenido a la raíz del repositorio de GitHub.
3. No subas únicamente `index.html` ni solamente `dist`.
4. En Vercel usa Vite, `npm run build` y salida `dist`.
5. Espera el estado **Ready**.
6. Abre la web y presiona `Ctrl + F5`.
7. En el menú debe aparecer **Laboratorio local**.
8. Abre dos pestañas y selecciona perfiles distintos.

No ejecutes SQL en Supabase para esta etapa.
