# Publicar Etapa 15 sin Supabase

1. Descomprime el ZIP.
2. Sube todo el contenido a la raíz del repositorio de GitHub.
3. No subas solamente `index.html` ni únicamente `dist`.
4. Espera el despliegue automático de Vercel.
5. En Vercel usa:
   - Framework: Vite
   - Install Command: npm install
   - Build Command: npm run build
   - Output Directory: dist
6. Cuando aparezca Ready, abre la web y presiona `Ctrl + F5`.
7. En el menú debe aparecer Mi Comunidad activa y el Laboratorio local como Etapa 15.

No debes ejecutar SQL para esta etapa.
