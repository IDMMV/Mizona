# Pasos para publicar y probar la Etapa 16

1. Descomprime el ZIP.
2. Sube todo el contenido a la raíz del repositorio de GitHub.
3. Espera que Vercel complete el despliegue.
4. Abre la web y presiona `Ctrl + F5`.
5. Confirma que Beneficios indique **Etapa 16 · multiusuario local**.
6. Abre una segunda pestaña con el botón del Laboratorio local.
7. Usa perfiles distintos en cada pestaña.

## Prueba de aprobación

- Carlos publica una oferta.
- José entra a Centro de Control → Beneficios.
- José presiona **Aprobar**.
- Carlos recibe una notificación.

## Prueba de cupón

- Otro perfil abre un cupón activo.
- Presiona **Obtener cupón**.
- En **Mis beneficios** aparece un código `MZ-...`.
- El responsable recibe una notificación.

## Prueba de reporte

- Abre una publicación ajena.
- Presiona **Reportar publicación**.
- José revisa el reporte en Centro de Control → Beneficios.

No ejecutes SQL. Esta entrega funciona completamente en modo local.
