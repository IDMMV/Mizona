# Publicar y probar Etapa 17 sin Supabase

## Publicación

1. Descomprime el ZIP.
2. Sube todo el contenido a la raíz de GitHub.
3. No subas únicamente `index.html` ni únicamente `dist`.
4. Espera que Vercel muestre **Ready**.
5. Abre MiZona y presiona `Ctrl + F5`.

## Configuración Vercel

- Framework Preset: `Vite`
- Install Command: `npm install`
- Build Command: `npm run build`
- Output Directory: `dist`

## Prueba de negocios

1. Abre MiZona en dos pestañas.
2. En una pestaña usa un usuario normal y crea un negocio.
3. En la otra pestaña cambia al administrador.
4. Ve a Centro de Control > Negocios y aprueba el negocio.
5. Regresa al primer usuario para abrir/cerrar su negocio.
6. Desde otro perfil guarda la ficha, califica y solicita contacto.

## Prueba de Marketplace

1. Publica un producto desde un usuario normal.
2. Apruébalo desde Centro de Control > Marketplace.
3. Cambia a otro perfil y guarda la publicación.
4. Pulsa Chatear con vendedor. Si todavía no son contactos, se enviará primero la solicitud.
5. Acepta la solicitud desde el perfil vendedor y abre MiZona Chat.
6. Marca la publicación como pausada o vendida desde el propietario.

## Importante

No ejecutes SQL. Los datos funcionan únicamente en el mismo navegador y dispositivo.
