
# Pasos Etapa 18.1

1. Sube todo el contenido del ZIP a GitHub.
2. Espera el despliegue en Vercel.
3. Abre MiZona con Ctrl + F5.
4. Entra al Laboratorio local.
5. Selecciona **Ian Hugo** o **Dylan Vilca**.
6. Verifica que no aparecen Centro de Control, Comités, Business, Ride, Marketplace, IA ni Negocios.
7. Cambia a **José** o **María Comité**.
8. Verifica que aparece el módulo **Comités**.
9. Abre Comités y prueba gastos, aportes, actas y respaldo.

Esta etapa no usa Supabase y no requiere SQL.
