# Publicar y probar la Etapa 18 sin Supabase

## 1. Actualizar GitHub

1. Descomprime el ZIP de la Etapa 18.
2. Abre tu repositorio de MiZona.
3. Sube todo el contenido de la carpeta a la raíz.
4. Reemplaza los archivos anteriores cuando GitHub lo solicite.
5. No subas solamente `index.html` o solamente `dist`.

## 2. Configuración de Vercel

- Framework Preset: `Vite`
- Install Command: `npm install`
- Build Command: `npm run build`
- Output Directory: `dist`

Cuando el despliegue muestre **Ready**, abre la web y presiona `Ctrl + F5`.

## 3. Prueba como estudiante

1. Entra en **Laboratorio local** y selecciona `JOSE1985` o `IAN_H`.
2. Abre **CampusHugo**.
3. Inscríbete en un curso.
4. Abre las lecciones y marca cada una como completada.
5. Realiza la evaluación final.
6. Al obtener al menos 70% y completar todas las lecciones, genera el certificado.
7. Abre la pestaña **Tareas** y entrega una actividad.

## 4. Prueba como profesor

1. Abre otra pestaña de MiZona.
2. Selecciona el perfil `PROFE_ANA`.
3. En CampusHugo aparecerá la pestaña **Profesor**.
4. Crea un curso nuevo; quedará pendiente.
5. Crea una tarea en uno de tus cursos.
6. Revisa y califica una entrega pendiente.

## 5. Prueba como administrador

1. Cambia al perfil `JOSE1985`.
2. Abre **Centro de Control > CampusHugo**.
3. Aprueba, verifica, pausa o rechaza cursos.
4. Revisa los reportes de contenido.

## Importante

No ejecutes ningún SQL. Esta etapa utiliza almacenamiento local y funciona entre pestañas del mismo navegador. No funciona todavía entre dispositivos diferentes.
