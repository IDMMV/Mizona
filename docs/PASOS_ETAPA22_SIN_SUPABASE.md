# Probar la Etapa 22 — Pagos MiZona

1. Descomprime el ZIP y reemplaza el contenido del repositorio.
2. En Vercel usa Vite, `npm install`, `npm run build` y salida `dist`.
3. Abre un perfil adulto o administrador.
4. Entra a **Pagos MiZona**.
5. Revisa los métodos públicos.
6. En **Probar flujo**, crea pagos simulados.
7. Con José administrador entra a **Administración**.
8. Activa o desactiva modelos, cambia comisiones y el método predeterminado.
9. Revisa movimientos y prueba completar, devolver o cancelar.

No ejecutes SQL. Ninguna operación mueve dinero real.
