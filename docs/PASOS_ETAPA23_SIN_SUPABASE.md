# Probar la Etapa 23

1. Descomprime el ZIP y reemplaza el repositorio.
2. Publica en Vercel con Vite, `npm run build` y salida `dist`.
3. Entra con un perfil adulto a **Verificación** y crea una solicitud.
4. Cambia al perfil José administrador y abre **Revisión administrativa**.
5. Marca identidad, RUC, dirección, licencia o acreditación.
6. Aprueba, observa, suspende o rechaza la solicitud.
7. Envía reportes desde la ficha pública y prueba la suspensión preventiva.

No ejecutes SQL. Esta etapa es una simulación local y no consulta registros oficiales.
