# Publicar y probar la Etapa 24

## 1. GitHub

Descomprime el ZIP y reemplaza el contenido del repositorio con esta etapa.

## 2. Vercel

Usa:

- Framework Preset: Vite
- Install Command: npm install
- Build Command: npm run build
- Output Directory: dist

No necesitas variables de Supabase para probar.

## 3. Probar Usuarios y Sync

1. Entra con José o un administrador local.
2. Abre **Usuarios y Sync**.
3. Ejecuta **Revisión automática**.
4. Revisa los perfiles listos para migración.
5. Crea un dispositivo de prueba.
6. Descarga el respaldo local.
7. Crea un plan de migración.
8. Descarga el plan JSON.
9. Cambia reglas de sincronización y guarda.

## 4. Seguridad

Las cuentas estudiantiles no ven este módulo. La protección de menores debe permanecer activa antes de cualquier migración.

## 5. Estado actual

Esta etapa no sube datos a Supabase ni a otro servidor. Solo prepara la migración segura.
