# Publicar y probar la Etapa 27

## Publicación
1. Descomprime el ZIP.
2. Reemplaza todo el repositorio de GitHub.
3. En Vercel usa Vite, `npm run build` y carpeta `dist`.
4. No ejecutes SQL.

## Prueba principal
1. Ingresa como José o María.
2. Abre **Calidad y piloto**.
3. Ejecuta el diagnóstico automático.
4. Completa el checklist por módulo.
5. Registra una incidencia de prueba y luego ciérrala.
6. Agrega participantes del colegio, comité y negocio.
7. Crea un candidato de publicación.

## Regla importante
Una incidencia crítica abierta o una prueba fallida debe bloquear el candidato. Esta etapa no reemplaza pruebas de seguridad profesionales ni una revisión legal.
