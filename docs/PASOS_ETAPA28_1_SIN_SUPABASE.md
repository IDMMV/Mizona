# Probar Etapa 28.1 — Comité completo unificado

1. Reemplaza el contenido del repositorio con esta versión.
2. Publica en Vercel con Vite, `npm run build` y carpeta `dist`.
3. Entra con un perfil adulto y abre **Comités**.
4. Revisa las pestañas Inicio, Cuotas, Quién pagó, Ingresos, Gastos, Comunicados, Eventos, Actas, Documentos, Miembros, Reportes y Configuración.
5. Registra una cuota, un pago parcial y un gasto con detalle.
6. Descarga el estado de pagos y los gastos en CSV.
7. Usa **Imprimir / Guardar PDF** para generar una rendición.

No requiere SQL. Los datos continúan guardados en el navegador y se actualizan entre pestañas del mismo equipo.
