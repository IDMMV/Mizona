# Probar la Etapa 28

1. Publica todo el proyecto en GitHub/Vercel.
2. Entra con un perfil adulto o administrador.
3. Abre **Comités**.
4. Crea una cuota o actividad.
5. Registra pagos de diferentes alumnos.
6. Abre **Quién pagó** para revisar pendientes.
7. Envía recordatorios simulados.
8. Registra gastos y revisa el saldo.
9. Descarga el CSV para abrirlo en Excel.

No requiere SQL. Los datos se guardan localmente en el navegador.
