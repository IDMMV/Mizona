# Etapa 30.14 · Temas desde Centro de Control

Incluye:
- Selector de color principal desde Centro de Control > Apariencia.
- 3 colores: Verde fresco, Azul moderno y Morado suave.
- Modo claro y modo noche.
- Persistencia en localStorage por dispositivo.
- Variables CSS globales aplicadas a menú, botones, tarjetas, headers e iconos.

Uso:
1. Abrir Centro de Control.
2. Entrar a Apariencia.
3. Elegir color y modo.
4. El cambio se aplica al instante.
