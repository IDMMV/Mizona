# Etapa 30.15 · Temas globales desde Supabase

## Qué cambia

- El color principal ahora puede ser global para todos los usuarios.
- Solo el administrador puede cambiar el color global desde Centro de Control > Apariencia.
- Colores disponibles: Verde fresco, Azul moderno y Morado suave.
- El modo claro/noche queda como preferencia personal por usuario o dispositivo.
- Si Supabase no está activo, los cambios se guardan solo en el navegador.

## Supabase

Ejecuta el archivo:

`supabase/ETAPA30_15_TEMAS_GLOBALES.sql`

Luego entra a la web con un usuario administrador y cambia el color en:

Centro de Control > Apariencia

## Recomendación

- Color global: Verde fresco.
- Modo noche: personal para quien trabaje en celular, cocina, caja o de noche.
