# Publicar y probar Etapa 30.1

## 1. Publicar

1. Descomprime el ZIP.
2. Reemplaza el contenido del repositorio en GitHub.
3. Espera el despliegue automático de Vercel.
4. En el celular, actualiza dos veces o limpia caché si ves la versión anterior.

## 2. Probar pestañas del comité

1. Entra a **Comités**.
2. Abre **Participantes**.
3. Selecciona una cuota, por ejemplo `Vestimenta danza`.
4. Marca quién participa y quién no participa.
5. Abre **Quién pagó**.
6. Verifica que a los que no participan les aparezca `No participa` y `No se cobra`.
7. Registra un pago en **Ingresos**.
8. Vuelve a **Quién pagó** y valida el estado.

## 3. Probar botón atrás del celular

1. Entra a un módulo desde MiZona.
2. Cambia a otra pantalla o pestaña del comité.
3. Presiona el botón atrás del celular.
4. Debe retroceder dentro de la app antes de salir del navegador.

## 4. Sin SQL nuevo

Esta corrección no requiere SQL nuevo. Solo actualiza la web.
