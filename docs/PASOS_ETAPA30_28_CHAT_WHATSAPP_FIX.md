# Etapa 30.28 - Chat móvil tipo WhatsApp

Cambios:
- El botón Ver chats vuelve al listado interno sin salir del módulo Chat.
- El botón atrás interno conserva el módulo Chat.
- La tecla atrás del celular mantiene el flujo: conversación -> lista de chats -> pestaña anterior.
- La lista móvil usa estilo oscuro tipo WhatsApp: título, buscador, chips y conversaciones compactas.
- La conversación móvil usa encabezado oscuro, mensajes tipo burbuja y caja de texto fija abajo.
- No se muestra el aviso global dentro de la conversación fullscreen.
