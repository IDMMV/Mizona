# Etapa 30.2 · Comité Excel y panel administrativo

Cambios incluidos:

- Exportación real a Excel `.xlsx` desde Reportes.
- Excel con hojas separadas: Resumen, Participantes, Cuotas, Quién pagó, Ingresos, Gastos, Comunicados, Eventos, Actas y Documentos.
- Menú de Comité simplificado: Inicio, Participantes, Pagos, Gastos, Comunicados, Reportes y Más.
- Tabla administrativa de participantes con buscador, estado, concepto activo y acción para ver pagos.
- Importación de participantes desde archivo CSV generado por Excel con columnas: Alumno, Apoderado, Celular.
- Tabla tipo sistema para control de pagos y gastos documentados.
- Se mantiene botón único de Cerrar sesión en barra lateral.
- Se mantiene botón visible de Solicitar permiso en Nube y Push.

Importante para GitHub:

No subir `node_modules` ni `.git`. Vercel instala dependencias automáticamente con `npm install`.
