# Sprint 1 - Foundation

## Objetivo
Crear la base real de MiZona Enterprise V8 con React + Vite.

## Pantallas incluidas
- Mi Panel
- Mi Comunidad base
- MiZona Chat base
- MiZona Transfer
- Beneficios placeholder
- Negocios placeholder
- Centro de Control Enterprise
- Login/Registro/Recuperación visual
- Perfil

## Reglas implementadas visualmente
- Usuario único
- Chat escolar limitado
- Transfer temporal de 7 días
- Módulos activables desde administración
- Diseño responsive
