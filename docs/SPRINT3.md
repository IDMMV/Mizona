# Sprint 3 — Beneficios y oportunidades

## Entregado

- Radar visual de oportunidades.
- Categorías: ofertas, empleos, eventos, campañas y cupones.
- Búsqueda y filtros en tiempo real.
- Guardado local de favoritos dentro del prototipo.
- Detalle modal de cada oportunidad.
- Acciones contextuales: obtener cupón, postular, asistir, ayudar y reservar.
- Compartir por canales externos preparado visualmente.
- Centro de Control con moderación de campañas y métricas.
- Esquema SQL Supabase para oportunidades, favoritos y acciones.

## Reglas

- Toda oportunidad debe tener responsable, zona, inicio, vencimiento y estado.
- Solo se muestran oportunidades activas y vigentes.
- Las métricas verificables se registran como acciones.
- Los sorteos con pago no se incluyen en este sprint.
