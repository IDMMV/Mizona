# Sprint 4 — Negocios y lugares

## Objetivo
Mostrar todo lo que existe en la zona, aunque el negocio no esté afiliado, y ofrecer funciones avanzadas a perfiles reclamados y verificados.

## Incluye
- Buscador y categorías locales.
- Filtros: abierto ahora y afiliado MiZona.
- Orden por recomendación, distancia o calificación.
- Fichas de lugares afiliados y no afiliados.
- Beneficios visibles en perfiles afiliados.
- Favoritos locales.
- Flujo para reclamar un negocio.
- Flujo comunitario para sugerir lugares faltantes.
- Acciones de compartir, ruta y contacto.
- Esquema SQL de lugares, reclamos, sugerencias, favoritos y acciones.

## Siguiente conexión real
Conectar `Businesses.jsx` con Supabase para sustituir los datos simulados por registros reales, y añadir moderación de reclamos desde Centro de Control.
