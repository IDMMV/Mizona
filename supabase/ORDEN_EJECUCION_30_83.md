# Orden de publicación
1. Crear respaldo del proyecto Supabase.
2. Ejecutar `MI_ZONA_SQL_CONSOLIDADO_30_83.sql` primero en un proyecto de prueba.
3. Revisar políticas con nombres duplicados si el proyecto ya contiene tablas anteriores.
4. Configurar buckets, Auth URLs y variables de entorno.
5. Probar con dos usuarios reales antes de producción.

No se incluyen credenciales, claves privadas ni configuración Firebase.
